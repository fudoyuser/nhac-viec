Kết nối GitHub

Website lưu công việc vào file tasks.json trong repo. Bạn cần một token có quyền ghi vào repo này. Token chỉ lưu trong trình duyệt của bạn.

Tạo token tại GitHub → Settings → Developer settings → Fine-grained tokens. Chọn đúng repo này, quyền Contents: Read and write.
